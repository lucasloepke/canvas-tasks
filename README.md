# Simple Canvas Tasks

A small Chrome extension that replaces the Canvas dashboard To Do sidebar with a
cleaner task list and due-date countdowns. No accounts, ads, trackers, or
servers.

[Get it on the Chrome Web Store](https://chromewebstore.google.com/detail/dejmhgkaogjhiannogiggcffkhodeoek)

## Features

- Tabs for **Tasks**, **Posts** (announcements), and **Calendar**
- Countdowns like `3 days until due`, red when due within 24 hours
- Course colors match your dashboard
- Check off tasks to hide them (local only, doesn't touch Canvas)
- Add your own tasks
- Filter by Day / Week / 2 Weeks / Month
- Themes: Light, Light gray, Dark, Dark blue
- Keeps Canvas' Recent Feedback section

Runs on the dashboard and course home pages only. It reads from Canvas'
planner API using your existing login, and all settings are stored locally.

## Install from source

1. Go to `chrome://extensions` and turn on Developer mode.
2. Click **Load unpacked** and select this folder.
3. Reload your Canvas dashboard.
